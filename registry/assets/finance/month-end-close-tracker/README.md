# Month-End Close Tracker

A small, self-contained **web app** (single HTML file) for running a month-end close.

## What it solves
Close is a sequence of dependent tasks across owners and days. This app gives a shared
board: tasks, owners, dependencies, and per-day status — no spreadsheet wrangling.

## Features
- Day-by-day close calendar view.
- Task owners and blockers.
- Progress roll-up.

## Run it
Open `index.html` in a browser. Built with Claude Code; contains sample tasks only.
