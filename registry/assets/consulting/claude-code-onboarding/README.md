# Claude Code Onboarding for Consultants

A **training** guide that takes a non-engineer from zero to productive in Claude Code in
under an hour.

## Who it's for
Consultants, analysts, and PMs who are not software engineers but want to use Claude Code
for documents, data, and small tools.

## Contents
1. What Claude Code is (and isn't).
2. Installing and opening your first project.
3. The five things you'll do every day.
4. Working safely with client confidentiality in mind.
5. Where to find and share reusable assets (this Hub!).

## Format
Self-paced markdown with checkpoints. ~45 minutes.
